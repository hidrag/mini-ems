# 08 — UI and UX Guidelines

Design character: professional industrial monitoring application. Prioritise clarity, legibility, status visibility and information hierarchy.

- Consistent spacing and typography.
- Responsive desktop-first layout with usable tablet/mobile views.
- Clear labels and units.
- Distinguish live, stale, offline and simulated data.
- Never rely on colour alone for severity.
- Provide loading, empty, error and reconnecting states.
- Accessible contrast and keyboard navigation.
- Charts include units, ranges, legends and useful tooltips.
- Store UTC; display selected/local timezone.
- Use reusable components and feature-based organisation.
- TanStack Query for server state.
- Backend remains authoritative for permissions.
- Clearly label all telemetry as simulated.

Phase 1 only includes a basic app shell and API health/status page. Do not fabricate operational dashboard metrics.
